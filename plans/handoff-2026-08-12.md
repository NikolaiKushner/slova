## Что есть

**Словарь.** `/dictionary` — одно поле, растущая таблица, выбор набора, кнопка
Add. Перевод не дёргается на каждый символ: он случается по нажатию Add, один
запрос на весь список. Ниже — большая таблица с поиском, фильтром по набору,
сортировкой, пагинацией (10/25/50), чекбоксами и массовыми действиями
(перенести, добавить в набор, вынуть из набора, удалить).

**Общая база.** 8172 лексемы с переводами и озвучкой. Попадание стоит $0,
промах ~$0.0001 и тут же становится общим достоянием.

**Тренировки.** Шесть форматов плюс Brainstorm, каждая сначала спрашивает
наборы. Всё с клавиатуры: `1`–`4`, буквы, `Enter`.

**Расписание — FSRS** (`ts-fsrs`): стабильность, сложность, извлекаемость
вместо одного ease factor.

**Озвучка.** Файлы в Cloudflare R2, отдаются по `Lexeme.audioUrl`. Для слов без
записи — Web Speech API как фолбэк.

## Решения, которые не надо перерешивать

1. **Слово глобально у пользователя.** Одно слово в трёх наборах — одна запись,
   один прогресс. Идентичность — `normalizeKey(front)` из `lib/lexicon/key.ts`;
   ту же функцию обязан использовать лексикон, иначе посев не попадёт в
   собственный индекс.
2. **Наборы — теги, не папки.** Отсюда «вынуть из набора» отдельной командой:
   без неё слово, добавленное в два набора, не вынималось никак — эту дыру
   нашёл пользователь, а не тест.
3. **Миграции добавочные, историю не переписываем.**
4. **LLM — `claude-haiku-4-5`, structured outputs, стриминг.**
   - **`effort` на Haiku 4.5 не существует** — 400. Он есть у Sonnet 5 / Opus,
     которые втрое-впятеро дороже. «Самая дешёвая модель» и «low» —
     взаимоисключающи. Карта возможностей — `lib/llm/models.ts`, тест это
     фиксирует.
   - Prompt caching не использовать: минимальный префикс на Haiku 4.5 — 4096
     токенов, наш системный промпт ~250, кэш молча не создастся.
   - Batch API вдвое дешевле, но до 24 часов. Только посев.
5. **Общая база — кэш, а не истина.** `seed` и `llm` глобальны сразу; перевод,
   напечатанный человеком, — кандидат `isGlobal=false`, общим становится после
   второго независимого подтверждения. Плохое поколение гасится bump'ом
   `version`, без удаления данных.
6. **Пустой перевод — не ответ, а промах.** Модель отдаёт пустую строку, когда
   не может перевести (`was/were`). В базе он считался бы попаданием вечно.
7. **`UserWord.lexemeId` — без внешнего ключа**, намеренно.
8. **Лемматизация — вне рамок.** `monitor` и `monitored` пока разные записи.

## Окружение и грабли

- **База одна** — `neondb`, она же прод. Миграции авторить через
  `npx prisma migrate diff --from-config-datasource --to-schema
  ./prisma/schema.prisma --script` (только читает), применять деплоем.
  `migrate dev`, `migrate reset`, `db push` против прода не запускать — все три
  запрещены правилом в `.claude/settings.local.json`, включая обёртки
  `npm run db:push` и `npm run db:migrate`: запрет на `npx prisma …` их не
  ловил, а разрешение `npm run *` пропускало.
- **`dotenvx` печатает баннер в stdout.** При `migrate diff --script > file.sql`
  он попадает первой строкой в SQL и роняет `migrate deploy`. Смотреть `head -1`.
- **В Prisma 7 у `migrate diff` другие флаги:** `--to-schema`;
  `--from-migrations` требует shadow-базы.
- **`tsx` компилирует в CJS** — top-level await в скриптах не работает,
  оборачивать в `async function main()`.
- **Vercel Blob отключён** (Billing State: Inactive) — отдавал 403 на 6117
  файлах. Хранилище переехало в **Cloudflare R2** (`aws4fetch`, SigV4, бесплатно
  до 10 ГБ, egress $0). Публичный доступ включается отдельно от токена.
- **`/v1/audio/speech` у OpenAI не батчится** — Batch API его не принимает.
  Озвучка идёт обычными запросами, `tts-1`, concurrency 8. `scripts/build-audio.ts`
  отказывается стартовать без `R2_PUBLIC_URL`, чтобы не платить за файлы,
  которые некуда положить (один раз так и вышло — ~667 вызовов в никуда).
- **shadcn здесь на base-ui, не на Radix.** Кнопка-ссылка — `render={<Link/>}`,
  не `asChild`; `Select.Value` требует явного потомка-подписи.
- **`router.replace` с теми же параметрами не навигирует.** Обновить таблицу
  после правки можно только явным счётчиком `reload` — URL об этом не сообщит.
- **Web Speech API.** Утверждение живёт, пока на него есть ссылка (иначе GC
  съедает его молча); `cancel()` перед каждой фразой заклинивает Chrome;
  `speaking: true` без `onstart` — норма. `lib/practice/speech.ts` держит
  `inFlight`, флаг `interrupting` и дедлайн старта 3 с.
- **`npm test` перед пушем в `main` обязателен.** Dev-сервер, e2e и браузеры в
  агентских сессиях не запускать.
